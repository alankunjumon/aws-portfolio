AWS Serverless Architecture

How This Portfolio Works on AWS

This portfolio is built using a fully serverless AWS architecture. Static content is delivered globally through Amazon CloudFront, while the contact form travels through API Gateway, AWS Lambda, DynamoDB, and Amazon SES — following AWS security and scalability best practices.

CloudFront CDN S3 Static Hosting API Gateway AWS Lambda DynamoDB Amazon SES IAM Security

Architecture Diagram

Every request follows this serverless AWS architecture from the browser to the backend.

Why This Architecture?

Every AWS service in this portfolio was selected for scalability, security, low cost, and real-world cloud engineering practices.

☁️

CloudFront + S3

CloudFront caches static assets globally while Amazon S3 provides durable static website hosting. This combination delivers low latency, HTTPS support, and reduces bandwidth costs.

🚪

API Gateway

API Gateway exposes a secure REST endpoint for the contact form, handles CORS, and integrates directly with AWS Lambda without managing servers.

⚡

Serverless Lambda Backend

Lambda executes backend logic only when requests arrive, making the portfolio scalable, cost-efficient, and maintenance-free.

🗄️

DynamoDB + SES

DynamoDB permanently stores visitor messages while Amazon SES immediately sends an email notification, creating a fully automated contact workflow.

AWS Services Used

Each AWS service has a dedicated responsibility within this serverless portfolio architecture.

🪣

Amazon S3

Static Website Hosting

  • Hosts HTML, CSS and JavaScript.
  • Stores resume PDF and portfolio assets.
  • Private origin behind CloudFront.
☁️

Amazon CloudFront

Global CDN & HTTPS

  • Delivers content from edge locations.
  • Routes /api/* requests.
  • Enforces HTTPS.
🚪

Amazon API Gateway

REST API Layer

  • Receives POST requests.
  • Handles CORS configuration.
  • Triggers Lambda through proxy integration.
⚡

AWS Lambda

Serverless Backend

  • Python backend function.
  • Validates contact form input.
  • Stores data and sends email.
🗄️

Amazon DynamoDB

NoSQL Database

  • Stores every submission.
  • Uses timestamp as metadata.
  • Fully managed serverless database.
📧

Amazon SES

Email Notification Service

  • Sends contact notification emails.
  • Uses verified Gmail identity.
  • Serverless email delivery.
🔑

AWS IAM

Access Management

  • Least-privilege Lambda role.
  • DynamoDB + SES permissions only.
  • CloudWatch logging permissions.
📊

Amazon CloudWatch

Logging & Monitoring

  • Captures Lambda logs.
  • Debugs API requests.
  • Monitors backend execution.

Security & AWS Best Practices

Security was considered at every layer of this portfolio architecture following AWS Well-Architected principles.

🔒

HTTPS Everywhere

  • CloudFront redirects HTTP to HTTPS.
  • Encrypted communication between visitors and AWS.
🛡️

Origin Access Control (OAC)

  • S3 bucket is not publicly accessible.
  • Only CloudFront can read website content.
🔑

IAM Least Privilege

  • Lambda has access only to DynamoDB, SES and CloudWatch.
  • No unnecessary administrator permissions.
🌐

API Gateway + CORS

  • Only the frontend origin can call the API.
  • CORS enabled for controlled browser access.
📊

CloudWatch Logging

  • Every Lambda invocation is logged.
  • Useful for monitoring and troubleshooting.
⚡

Serverless by Design

  • No EC2 servers to patch or maintain.
  • Automatic scaling with AWS managed services.
